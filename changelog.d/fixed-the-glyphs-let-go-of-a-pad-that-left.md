- **Unplug the controller and the prompts stop naming it.** A pad that is disconnected sends no
  input, and the badges only ever followed input — so every glyph in the game went on showing pad
  buttons for hardware that had left the room, which is the exact thing the glyph system exists to
  prevent, arrived from the other direction. A second pad still plugged in is still a pad; only an
  empty hand falls back to the keyboard. And the controls tab had one row printing
  `OPT_BIND_MUSIC_MUTE` at the player, because the action was rebindable and nobody had written it a
  name.
